# samples 示例题库

这里是一份**脱敏的虚构示例题库**（无任何真实课程/账号数据），
用来在**不运行爬虫**的情况下快速体验「离线刷题网页」的全部功能，
也方便你验证自己的环境是否正常。

## 内容

| 文件 | 说明 |
| --- | --- |
| `示例_第一章 Python 入门.xlsx` | Excel 题库（含图片标注 `[图片: 文件名]`） |
| `示例_第一章 Python 入门.txt` | TXT 题库（UTF-8 带 BOM，记事本直接打开不乱码） |
| `示例_第一章 Python 入门.docx` | Word 题库（公式图片已直接内嵌） |
| `示例_第一章 Python 入门_图片/` | 题目图片目录（`formula01.png`、`formula02.png`） |

共 6 道题，覆盖：单选 / 多选 / 判断、题干附图、解析附图。

## 如何体验

1. 双击打开 `web-practice/index.html`。
2. 点击页面中央，导入上面任意一个格式的文件（如 `.xlsx`）。
3. 点顶部「🖼️ 选择图片文件夹」，选择 `示例_第一章 Python 入门_图片` 文件夹，
   题干/解析里的公式图片即可显示。
4. 开始刷题：选项即点即判，答错自动进「错题本」（数据存在浏览器 localStorage）。

## 重新生成

运行 `tools/gen_sample.py` 可重新生成这套示例文件（需要本机装有微软雅黑字体，
Windows 自带）。修改该脚本里的 `questions` 即可定制自己的示例。
