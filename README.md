# 学习通习题采集与本地刷题系统

本工具用于**采集本人学习通账号下某个习题页面（课程 / 章节测验 / 作业）的题目**，
导出为 **Excel / TXT / Word 三种格式**的题库，再通过一个**纯本地、无后端的刷题网页**
进行复习练习（支持错题本、题型筛选，三种格式均可导入）。

> ⚠️ 重要约束：本工具仅用于本人账号下习题的个人复习学习。
> 不实现登录、不越权抓取、不自动答题、不自动遍历课程页面。

## 运行环境

- 操作系统：Windows（字体解密依赖 Windows 系统字体；其他系统会自动回退到内置映射表）
- Python 3.9 ~ 3.12（开发验证环境：3.12.9；3.13+ 暂未验证）
- Microsoft Edge（需支持远程调试模式，本机已安装即可）

## 一、项目结构

```
chaoxing-exercise-crawler/
├─ crawler/
│  ├─ main.py            # 爬虫主程序：连接已打开的 Edge，采集指定 URL 页面中的习题
│  └─ requirements.txt   # Python 依赖清单
├─ web-practice/         # 离线刷题网页（双击即用，无需服务器）
│  ├─ index.html         # 刷题页面
│  ├─ xlsx.full.min.js   # 离线 Excel 解析库（SheetJS，已内置本地）
│  └─ mammoth.min.js     # 离线 Word 解析库（docx -> 文本，已内置本地）
├─ tests/                # 自动化自测脚本（见第六节）
├─ samples/              # 脱敏示例题库（不爬虫也能体验刷题网页，见「快速体验」）
├─ tools/
│  └─ gen_sample.py      # 重新生成 samples 示例题库的脚本
├─ start_edge_debug.bat  # 一键启动调试模式 Edge
├─ run_crawler.bat       # 一键运行爬虫（自动检查依赖）
├─ .gitignore            # Git 忽略规则（output/ logs/ 等本地数据不入库）
├─ LICENSE               # MIT 开源协议
└─ README.md             # 本说明
```

> 说明：`output/`（采集题库）与 `logs/`（运行日志）包含你的个人课程数据，
> 已在 `.gitignore` 中排除，**不会**被提交到 Git 仓库。
> `.vscode/` 内含本机 Python 解释器绝对路径，同样不入库。

## 快速体验（不运行爬虫也能先玩）

`samples/` 里有一份**脱敏的虚构示例题库**（含单选/多选/判断、公式图片），
用来快速验证刷题网页在你电脑上能否正常工作：

1. 双击打开 `web-practice/index.html`；
2. 导入 `samples/示例_第一章 Python 入门/` 子文件夹中的 `示例_第一章 Python 入门.xlsx`
   （或 `.txt` / `.docx`）；
3. 点「🖼️ 选择图片文件夹」→ 选 `samples/示例_第一章 Python 入门/示例_第一章 Python 入门_图片`，
   公式图片即可显示；
4. 开始刷题体验。

## 二、环境准备

1. 安装 Python 3.9 及以上版本（已安装可跳过）。
2. 安装依赖：

```bash
cd crawler
pip install -r requirements.txt
```

> 重要：如果使用 **VS Code** 运行（按 F5 调试），请确认终端左下角选中的
> Python 解释器与安装依赖时用的是同一个，否则会出现
> `ModuleNotFoundError: No module named 'playwright'`。
> 在 VS Code 右下角点击 Python 版本号选择解释器（选你刚才安装依赖用的那个），
> 然后在 VS Code 终端里重新执行 `pip install -r requirements.txt` 即可。

> 说明：Playwright 在本项目中只用于**连接你已经打开的 Edge 浏览器**（通过 CDP 协议），
> **不需要**执行 `playwright install` 下载浏览器内核，也不需要执行任何登录逻辑。

## 三、第一步：以远程调试模式启动 Edge（关键！）

爬虫要复用你 Edge 里已经登录好的学习通会话，必须以远程调试模式启动 Edge，让爬虫能连上来。

### 方式 B：使用独立的调试配置目录（推荐，实测最稳定）

> 说明：部分 Edge 版本（如 154.x）使用默认配置目录启动时，调试参数可能被忽略
> （表现为 Edge 正常打开但 9222 端口无监听）。使用独立配置目录可稳定解决，
> 且**不会关闭、不影响你日常使用的 Edge**，两者可并行运行。

**一键启动**：双击项目根目录的 `start_edge_debug.bat`，脚本会自动以调试模式
启动一个独立的 Edge 窗口（端口 9222，配置目录 `C:\edge-debug-profile2`）。

或手动执行：

```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222 --user-data-dir="C:\edge-debug-profile2" --remote-allow-origins=*
```

> 注意：`--remote-allow-origins=*` 是**必须**的参数。新版 Edge（111+）默认拒绝爬虫的
> 调试连接（报 403 / 连接超时），加上该参数后才能正常连接。

启动后：
1. 在弹出的 **Edge 窗口中手动登录学习通**（只需登录一次，Cookie 保存在该配置目录，之后长期免登录）；
2. 打开你要采集的页面：
   - 章节测验：进入课程 → 章节 → 点击“章节测验”并**打开测验页面**
   - 作业：进入课程 → 作业 → 打开某次作业页面
3. 复制浏览器**地址栏中的完整 URL**，稍后粘贴给爬虫。

### 方式 A：使用你的日常 Edge 配置（备用）

1. **完全退出**所有 Edge 窗口（任务栏托盘处也检查一下，确保没有后台进程）。
2. 按 `Win + R`，输入以下命令并回车（Windows 默认路径）：

```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222 --remote-allow-origins=*
```

如果上述路径不存在（64 位系统 Edge 装在 Program Files），改用：

```
"C:\Program Files\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222 --remote-allow-origins=*
```

3. 弹出的 Edge 窗口中，**手动登录学习通**（网页地址：https://i.chaoxing.com 或学校的学习通入口）。
4. 打开你要采集的页面：
   - 章节测验：进入课程 → 章节 → 点击“章节测验”并**打开测验页面**
   - 作业：进入课程 → 作业 → 打开某次作业页面
5. 复制浏览器**地址栏中的完整 URL**，稍后粘贴给爬虫。

> 小技巧：如果启动命令没有生效（新窗口没出现、或端口被占用），
> 确认 Edge 已完全退出后再试；也可以先执行一次 `taskkill /f /im msedge.exe` 清理残留进程。

### 验证调试端口是否开启

打开浏览器访问 `http://127.0.0.1:9222/json/version`，
能看到 JSON 信息（如浏览器版本、webSocketDebuggerUrl）即代表端口已开启。

## 四、第二步：运行爬虫采集习题

```bash
cd crawler
python main.py
```

按提示**粘贴上一步复制的页面 URL**，回车开始采集。
可一次粘贴**多个 URL**（每行一个，直接回车结束），程序会逐个采集每个页面。

也可以在命令行直接传 URL（免交互），支持多个：

```bash
python main.py "https://mooc1.chaoxing.com/exam-ans/xxxx"
python main.py "url1" "url2" "url3"    # 批量采集多个页面
```

> 批量采集的每个 URL 都是你显式提供的页面，程序仍**不会**自动翻页/遍历课程。

### 程序行为说明

| 行为 | 说明 |
| --- | --- |
| 登录 | 不做任何登录，复用你 Edge 中已登录的会话 |
| 采集范围 | 仅采集你粘贴的 URL 页面内的题目（**可一次粘贴多个 URL 逐个采集**），绝不自动翻页、不遍历课程 |
| 支持页面 | 作业页面（`mooc2/work/view`）、章节测验/考试页面（`exam-ans/examTest`）等 |
| 提取字段 | 课程名称、章节名称、题型、题干、A~F 选项、参考答案、解析 |
| 输出 | 每次采集在 `output/作业名称_日期_时间/` 子文件夹内生成三种格式与配套图片目录，例如 `output/第二章 选择题_20260927_221030/`（内含 `第二章 选择题_20260927_221030.xlsx / .txt / .docx` 与 `..._图片/`）。每次采集独立文件夹，**不覆盖旧题库** |
| 防风控 | 页面加载与滚动均带随机延时，模拟人工节奏 |
| 字体加密 | 学习通部分页面（如“第二章 单元测验”）会用自定义字体把题干汉字渲染成乱码码点。程序会自动提取页面字体并还原为正常汉字（内置常用映射表 + 系统黑体自动识别兜底） |
| 题目图片 | 题干/选项/解析中的图片（含数学公式、图形截图）会自动下载到 `output/作业名_日期_时间/作业名_日期_时间_图片/` 文件夹；TXT/Excel 中以 `[图片: 文件名]` 标注，Word 直接嵌入图片，刷题网页可选该文件夹显示图片 |
| 折叠答案 | 部分作业/测验的“参考答案/解析”默认折叠（点击“查看答案”才加载）。程序会自动点击展开后再提取；不会误触“提交/保存”等按钮 |
| 日志 | 控制台实时打印 + `logs/crawler_时间戳.log` 完整日志 |

## 五、第三步：离线刷题

1. 打开文件夹 `web-practice`。
2. **双击 `index.html`**，浏览器会直接打开刷题页面（无需服务器、无需联网）。
3. 点击页面中央区域（或直接拖拽）导入题库，**支持三种格式**：
   - `output/作业名称_日期_时间/` 子文件夹内的 `作业名称_日期_时间.xlsx`（Excel）
   - `作业名称_日期_时间.txt`（TXT，与爬虫导出格式完全一致）
   - `作业名称_日期_时间.docx`（Word）
4. **若题库含图片/公式**：导入后点击顶部「🖼️ 选择图片文件夹」，选择同一子文件夹内的
   `作业名称_日期_时间_图片` 文件夹，题目中的图片/公式截图即可显示。
5. 开始刷题：

   - **单选 / 判断**：点击选项后**立即判对错**；
   - **多选**：先勾选多个选项，再点「提交答案」判定；
   - 每道题下方可展开「查看答案与解析」；
   - 顶部按钮可筛选 **单选 / 多选 / 判断 / 错题本**；
   - 「🔀 乱序」可打乱题目顺序再刷（防止背答案位置），再点一次恢复原序；
   - 「📤 导出错题」把错题本导出为一个 TXT 题库文件（与爬虫格式一致，
     可再次导入继续刷）；
   - 答错的题会自动进入**错题本**（保存在浏览器 localStorage，关闭页面不丢失）；
   - 「重置进度」可清空答题记录与错题本。

> 提示：请用同一浏览器打开页面，错题本数据存在当前浏览器的 localStorage 中；
> 清理浏览器缓存 / 换浏览器会清空错题记录。切换题库时按题干自动匹配原答题记录。

## 七、常见问题排查

| 问题 | 原因与解决 |
| --- | --- |
| 连接 Edge 失败 / Connection refused | 未以 `--remote-debugging-port=9222` 启动 Edge，或 Edge 未完全退出导致端口未生效。按第三节重新操作。 |
| 打开页面后提示“未找到题目” | ① 页面不是章节测验/作业页面；② 页面加载太慢，可重试或稍等后再运行；③ 学习通改版导致 DOM 结构变化，把页面 URL 与截图反馈给开发者。 |
| 题目解析不全 / 答案为空 | ① 页面本身没提供答案（如**未作答**的测验，点了“查看答案”也没内容）；② 不同学校模板略有差异，程序已内置多种选择器兼容；若仍失败，可在爬虫日志（logs 目录）中查看诊断信息。 |
| 日志显示“已点击展开 N 个按钮”但没有答案 | 说明页面已点击展开，但答案内容是异步加载或本身不提供（未作答/老师未开启答案查看），属正常现象。 |
| 导出的题干/选项全是乱码（如“摳抝鬦…抙択为”） | 这是学习通**字体加密**反爬：服务器下发乱码码点、浏览器用自定义字体渲染成正常汉字。程序已自动提取页面字体并还原（内置映射 + 黑体自动识别）。若个别字仍还原错误：① 查看日志中“自动识别新增 N 个字”的提示；② 在 `crawler/main.py` 的 `CX_FONT_MAP` 中补充 `0x码点: "正确汉字"`，把页面字体（程序日志会提示存放位置）反馈给开发者更新内置表。 |
| 采集到重复题 | 页面本身可能有重复题目（如试卷多套合并），属正常现象，可在 Excel 中自行去重。 |
| 刷题页面提示“解析文件失败” | 选择的不是爬虫导出的 xlsx / txt / docx（或文件被破坏），请重新运行爬虫生成题库。确认 Word 文件时 `mammoth.min.js` 与 `index.html` 在同一目录。 |
| 网页里图片不显示（虚线框） | 题库含图片标注但还没选图片文件夹：点顶部「🖼️ 选择图片文件夹」，选择 output 下与题库同一子文件夹内的 `作业名称_日期_时间_图片` 文件夹即可。 |
| 导出文件里图片显示为 `[图片: 文件名]` | 这是正常标注，图片文件在 output 下对应作业子文件夹的 `..._图片` 目录中；Word 版本会直接内嵌图片。 |
| 端口 9222 被占用 | 说明已有程序占用该端口。可改用其他端口（如 9223），同时修改 `crawler/main.py` 中的 `CDP_URL`。 |
