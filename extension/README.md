# 学习通题库采集 · 浏览器扩展（extension/）

在 Edge / Chrome 浏览器里**一键采集当前学习通页面**（章节测验 / 作业）的题目，
按需勾选导出 Excel / TXT / Word 三种格式，文件保存在浏览器“下载 / 学习通题库 /”文件夹。

- 只采集**当前这一个页面**，不翻页、不遍历、不自动答题；
- 不需要运行 Python，不需要登录逻辑——直接用浏览器里**已登录的学习通会话**；
- 自动识别字体加密（font-cxsecret）、自动展开“查看答案/解析”、自动下载题目图片。

> 与 `crawler/main.py`（Python 版）功能等价，二者可任选其一，也可同时使用。

---

## 一、安装（加载扩展）

1. 打开 Edge，地址栏输入 `edge://extensions` 回车；
2. 打开右上角 **“开发人员模式”** 开关；
3. 点击 **“加载解压缩的扩展”**，选择本文件夹：`chaoxing-exercise-crawler/extension`；
4. 浏览器工具栏出现 📚 图标即安装成功。

Chrome 用户：进入 `chrome://extensions`，同样打开“开发者模式”后加载即可。

> 注意：扩展会随浏览器更新而失效（Edge 更新后需重新加载一次），文件本身不受影响。

## 二、使用步骤

1. 在 Edge 里打开学习通并**手动登录**；
2. 打开要采集的 **章节测验 / 作业页面**（不要打开课程主页）；
3. 点击工具栏 📚 图标；
4. 勾选需要的导出格式（Excel / TXT / Word，可多选，勾选会被记住）；
5. 点击 **“采集本页题目”**，等待弹窗显示完成与文件清单；
6. 到浏览器默认下载目录下 `学习通题库/作业名_日期_时间/` 查看：
   - `作业名_日期_时间.xlsx / .txt / .docx`（勾选了哪种就有哪种）
   - `作业名_日期_时间_图片/`（题目图片，如有）

> 弹窗中的“课程名称”会自动识别（扫描已打开的标签页，按 courseId 精确匹配课程卡片，
> 结果会记忆，下次同课程直接复用），识别不到时可手动填写。

## 三、与 Python 版的关系

| 能力 | 扩展版（本目录） | Python 版（crawler/main.py） |
|---|---|---|
| 需要运行环境 | 浏览器即可 | Python 3.12 + Playwright |
| 登录方式 | 复用浏览器已登录会话 | 复用已开启远程调试的 Edge 会话 |
| 采集范围 | 仅当前页面 | 仅传入 URL 的页面 |
| 导出格式 | Excel / TXT / Word 自选 | Excel / TXT / Word |
| 导出位置 | 浏览器“下载/学习通题库/” | 项目 output/ 下 |
| 字体加密识别 | 内置 35 字映射 + 字形比对 | 内置 35 字映射 + fonttools 比对 |
| 自动答题 / 遍历 | 无 | 无 |

两个版本都**不做**越权抓取与自动答题，仅用于本人账号下习题的个人复习学习。

## 四、文件说明

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单：权限（activeTab/scripting/downloads）、学习通域名 |
| `popup.html` / `popup.js` | 弹窗：格式勾选、注入采集、显示结果 |
| `collect.js` | 采集核心（页面上下文运行）：定位题目、展开答案、提取字段、图片占位 |
| `font-common.js` | 字体解密公共模块（内置映射表 + canvas 字形比对） |
| `background.js` | 后台：下载图片、生成 xlsx / txt / docx |
| `xlsx.full.min.js` / `jszip.min.js` | 第三方库（SheetJS / JSZip），仅本地使用 |
| `gen_font_common.py` 等 | 生成脚本（重新生成 font-common.js 等，一般不需要运行） |
| `icons/` | 扩展图标 |

## 五、隐私与安全

- 扩展只在**学习通域名**（`*.chaoxing.com`、`*.edu.cn`）下生效；
- 采集结果只写入**本机浏览器下载目录**，不上传任何服务器；
- 扩展不含登录、密码、扫码逻辑，数据仅来自你当前已登录的页面。

## 六、常见问题

- **提示“非学习通域名”**：请确认当前标签页就是学习通题目页面。
- **解析到 0 题**：页面可能未加载完，等 2~3 秒再点一次；或确认当前是“章节测验/作业”页面而非课程主页。
- **章节测验采不到“参考答案/解析”**：已批阅的回顾页（只有“我的答案”）平台本身不下发正确答案，
  任何工具都提取不到。可尝试从课程目录-任务点-章节测验的**作答入口**打开（未作答/可查看解析的页面）再采集。
- **图片没下载**：个别图片跨域受限时会在文件中标注“[图片: 下载失败]”，不影响文字题目。
- **Word 文件打不开**：请用 Microsoft Word / WPS 打开；若提示损坏，重采一次即可。
- **支持哪些题型**：单选、多选、判断、填空、简答、名词解释等。填空题/简答题按“题干 + 参考答案/解析”采集（无选项），
  刷题页中此类题型提供“对照答案”自评。
